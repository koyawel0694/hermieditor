## 4. FFmpeg Mixing Recipes

### Rule of Thumb: Spoken Dialogue Primacy
As codified in `my-rules.md`, dialogue is **ALWAYS** the dominant foreground element (-18 to -22 dBFS RMS). Never let SFX overpower speech:
- Subtle UI / Pops / Clicks: `volume=0.20 to 0.25`
- Transition Whooshes: `volume=0.25 to 0.30`
- Impact Hits / Booms: `volume=0.30 to 0.35`
- High-intensity meme punctuation: `volume=0.25 to 0.35` (never 1.0)

### Example: Overlaying SFX at a specific timestamp
```bash
# Overlay a clean pop at 3.5 seconds and a whoosh at 8.0 seconds:
ffmpeg -y -i speech_video.mp4 \
  -i my-sounds/explainer/pop-clean.mp3 \
  -i my-sounds/explainer/whoosh-transition-fast.mp3 \
  -filter_complex "
    [1:a]adelay=3500|3500,volume=0.25[pop];
    [2:a]adelay=8000|8000,volume=0.25[whoosh];
    [0:a][pop][whoosh]amix=inputs=3:duration=first:normalize=0[aout]
  " \
  -map 0:v -map "[aout]" -c:v copy output.mp4
```

### Example: Drama Cliffhanger Freeze-Frame with Braam + Sub-Bass
```bash
# Add Braam and Bass Drop at cliffhanger timestamp (e.g. 58.5s):
ffmpeg -y -i episode.mp4 \
  -i my-sounds/mini-drama/cinematic-braam.mp3 \
  -i my-sounds/mini-drama/cinematic-sub-boom.mp3 \
  -filter_complex "
    [1:a]adelay=58500|58500,volume=0.35[braam];
    [2:a]adelay=58500|58500,volume=0.30[boom];
    [0:a][braam][boom]amix=inputs=3:duration=first:normalize=0[aout]
  " \
  -map 0:v -map "[aout]" -c:v copy episode_cliffhanger_master.mp4
```
