# Project Start — Creative Direction Mode

Ask this **once per new project** if the user hasn't already answered or described their direction clearly.

**How should I choose the motion-graphics style for this project?**

**A — Auto-director (recommended)**  
I'll analyze your script, format, audience, existing assets, tools, and reference videos, then choose the best motion-graphics styles and explain the plan briefly. I'll make scene-level choices automatically and won't keep asking for approval.

**B — Let me choose**  
Show me the style menu. I'll choose one main visual style and up to two supporting styles.

**C — My creative direction**  
I'll tell you my own thoughts about the look, effects, pacing, colors, transitions, and references. Follow my direction unless a technical or factual issue prevents it.

**D — Hybrid**  
Propose a creative direction and visual treatment first. Wait for my approval/changes before producing the full edit.

Reply A, B, C, or D. You can add a note such as “clean minimalist graphics, but use collage for key moments.”

## Parsing rules
- If the user says “you decide,” “automatic,” or equivalent, select A.
- If they ask to select a style, choose B.
- If they provide a detailed style brief, treat it as C unless they explicitly request a proposal for approval.
- If they ask to propose/review/approve the visual plan first, choose D.
- Do not ask if the message has already provided the choice.
- Store the choice in the project brief so the same project does not get asked again.
